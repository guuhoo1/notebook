# Notebook 项目部署指南

## 服务器环境要求

- **操作系统**: CentOS 7+ / Ubuntu 18+ / Debian 10+
- **CPU**: 2 核+
- **内存**: 4GB+
- **硬盘**: 20GB+
- **软件要求**:
  - JDK 17+
  - Nginx 1.18+
  - MySQL 8.0+
  - Redis 6.0+

---

## 第一部分：服务器环境准备

### 1.1 安装 JDK 17

```bash
# Ubuntu/Debian
apt update
apt install openjdk-17-jdk -y

# CentOS
yum install java-17-openjdk java-17-openjdk-devel -y

# 验证安装
java -version
```

### 1.2 安装 Nginx

```bash
# Ubuntu/Debian
apt install nginx -y

# CentOS
yum install epel-release -y
yum install nginx -y

# 启动并设置开机自启
systemctl start nginx
systemctl enable nginx
```

### 1.3 安装 MySQL 8.0

```bash
# Ubuntu/Debian
apt install mysql-server -y

# CentOS
yum install mysql-server -y

# 启动服务
systemctl start mysqld
systemctl enable mysqld
```

### 1.4 安装 Redis

```bash
# Ubuntu/Debian
apt install redis-server -y

# CentOS
yum install redis -y

# 启动服务
systemctl start redis
systemctl enable redis
```

### 1.5 创建数据库

```sql
CREATE DATABASE notebook DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'notebook'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON notebook.* TO 'notebook'@'localhost';
FLUSH PRIVILEGES;
```

## 第二部分：本地构建

### 2.1 构建前端

```bash
cd web
pnpm install
pnpm build
```

前端构建产物位于 `web/dist/`

### 2.2 构建后端

```bash
cd server
mvn clean package -DskipTests
```

后端 JAR 文件位于 `server/target/notebook-server-1.0.0.jar`

## 第三部分：服务器部署

### 3.1 上传文件到服务器

```bash
# 创建部署目录
mkdir -p /opt/notebook
mkdir -p /var/www/notebook-web
mkdir -p /data/notebook/uploads

# 上传后端 JAR
scp server/target/notebook-server-1.0.0.jar root@your-server:/opt/notebook/

# 上传前端构建产物
scp -r web/dist/* root@your-server:/var/www/notebook-web/

# 上传 Nginx 配置
scp deploy/nginx.conf root@your-server:/etc/nginx/sites-available/notebook
```

### 3.2 配置后端

创建后端配置文件 `/opt/notebook/application-prod.yml`:

```yaml
server:
  port: 8080
  servlet:
    context-path: /api

spring:
  application:
    name: notebook-server
  data:
    redis:
      host: localhost
      port: 6379
      password:
      database: 0
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/notebook?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false
    username: notebook
    password: your_password
  servlet:
    multipart:
      max-file-size: 10MB
      max-request-size: 20MB

mybatis-plus:
  configuration:
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl

file:
  upload:
    path: /data/notebook/uploads
    base-url: /uploads
```

创建启动脚本 `/opt/notebook/start.sh`:

```bash
#!/bin/bash
export JAVA_OPTS="-Xms256m -Xmx512m -Dfile.encoding=utf-8"
export SPRING_PROFILES_ACTIVE=prod
java $JAVA_OPTS -jar /opt/notebook/notebook-server-1.0.0.jar --spring.config.location=/opt/notebook/application-prod.yml
```

```bash
chmod +x /opt/notebook/start.sh
```

### 3.3 配置 Nginx

```bash
# 启用站点配置
ln -sf /etc/nginx/sites-available/notebook /etc/nginx/sites-enabled/notebook

# 测试配置
nginx -t

# 重载 Nginx
systemctl reload nginx
```

### 3.4 启动服务

```bash
# 启动后端
cd /opt/notebook
nohup ./start.sh > /var/log/notebook-backend.log 2>&1 &

# 检查服务状态
ps aux | grep notebook-server
curl http://127.0.0.1:8080/api/ping

# 重启 Nginx
systemctl restart nginx
```

## 第四部分：使用 systemd 管理服务

创建后端服务文件 `/etc/systemd/system/notebook-backend.service`:

```ini
[Unit]
Description=Notebook Backend Service
After=network.target mysql.service redis.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/notebook
ExecStart=/opt/notebook/start.sh
Restart=on-failure
RestartSec=10
StandardOutput=append:/var/log/notebook-backend.log
StandardError=append:/var/log/notebook-backend.log

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable notebook-backend
systemctl start notebook-backend
systemctl status notebook-backend
```

## 常见问题

### 1. 后端启动失败

检查日志：
```bash
cat /var/log/notebook-backend.log
```

常见原因：
- 数据库连接失败 - 检查 MySQL 配置
- Redis 连接失败 - 检查 Redis 配置
- 端口被占用 - 修改 `server.port`

### 2. 前端无法访问 API

- 检查 Nginx 配置中的 `proxy_pass` 是否正确
- 检查后端服务是否正常运行
- 检查防火墙是否开放 80 和 8080 端口

### 3. 文件上传失败

- 检查 `/data/notebook/uploads` 目录权限
- 检查 Nginx `client_max_body_size` 配置

## 防火墙配置

```bash
# 开放端口
firewall-cmd --permanent --add-port=80/tcp
firewall-cmd --permanent --add-port=8080/tcp
firewall-cmd --reload

# 或者使用 iptables
iptables -A INPUT -p tcp --dport 80 -j ACCEPT
iptables -A INPUT -p tcp --dport 8080 -j ACCEPT
```
